# 刷抖音神器

基于 **ESP32-C3** 的蓝牙触控遥控器，通过模拟 HID 绝对坐标触摸手势，控制手机短视频 App 进行刷视频、点赞、评论、分享等操作。

- **主控**：ESP32-C3 Super Mini
- **触摸芯片**：Holtek BS816A-1（6 键，本项目使用 5 键）
- **通信方式**：BLE（NimBLE）HID Digitizer 绝对坐标触控
- **开发环境**：Arduino IDE

---

## 功能特性

- 免 Root、免安装 App，手机当作普通 HID 触控设备连接
- 上下滑切换视频（上键=上一个，下键=下一个）
- 双击点赞、打开/关闭评论区、选择好友分享
- 分享状态下可循环选择好友头像，`love` 键切换选中/取消
- 全流程**无阻塞**动作执行器（帧队列 + `millis()`），不卡主循环
- 悬停移动 + 缓动曲线（ease-out quintic），光标位置全程连续、先快后慢丝滑
- 上电/BLE 连接防误触发（首次读取建立基准）

## 硬件接线

### BS816A-1 触摸芯片

| 引脚 | 接法 | 说明 |
|------|------|------|
| `VDD` | `3.3V` | 供电（与 ESP32-C3 GPIO 电平匹配） |
| `VSS` | `GND` | 地 |
| `OMS` | `GND` | CMOS 直接输出，**高电平有效** |
| `LSC` | 悬空（开路） | 一般省电模式，待机响应更快 |
| `Key1~Key5` | 触摸焊盘 | 5 个触摸按键 |
| `Key6` | `GND` | **未使用的按键必须接地** |
| `Kout1` | ESP32-C3 `GPIO0` | 上键 |
| `Kout2` | ESP32-C3 `GPIO1` | 下键 |
| `Kout3` | ESP32-C3 `GPIO2` | 分享键 |
| `Kout4` | ESP32-C3 `GPIO3` | 评论键 |
| `Kout5` | ESP32-C3 `GPIO4` | love 键 |

### LED

板载 LED 接 `GPIO8`：慢闪 = 等待连接，常亮 = 已连接。

> 引脚定义见 [touch.ino](touch.ino#L19-L25)，可在源码中修改。

## 编译与烧录

1. 用 Arduino IDE 打开 `touch.ino`
2. 安装上述依赖库
3. 选择开发板 `ESP32C3 Dev Module`
4. 选择正确串口，点击上传

烧录完成后，设备广播名为 `Video Remote`，在手机蓝牙中连接即可（无需配对码）。

## 使用方法

### 基本按键

| 按键 | 普通状态 | 分享状态 | 评论状态 |
|------|----------|----------|----------|
| `KOUT1` 上键 | 下滑（上一个视频） | 上一个头像 | 下滑评论 |
| `KOUT2` 下键 | 上滑（下一个视频） | 下一个头像 | 上滑评论 |
| `KOUT3` 分享键 | 打开分享面板 | 确认/中断分享 | 无效 |
| `KOUT4` 评论键 | 打开评论区 | 中断分享 | 关闭评论区 |
| `KOUT5` love 键 | 点赞 | 选中/取消头像 | 无效 |

### 分享流程

1. 普通状态下按 `分享键` → 点击分享按钮，打开分享面板，并自动悬停到**第一个头像**（不点击）
2. 按 `上键`/`下键` → 在 5 个头像间循环切换（悬停移动，不点击）
3. 按 `love 键` → 点击当前头像，切换**选中 / 取消选中**
4. 选择完成后，再次按 `分享键`：
   - **已选过头像** → 点击确认分享按钮，完成分享
   - **未选任何头像** → 默认中断分享，关闭面板
5. 中途按 `评论键` → 点击面板外区域，随时中断分享

### 评论流程

1. 普通状态下按 `评论键` → 打开评论区，进入评论状态
2. 评论状态下按 `上键`/`下键` → 正常滑动评论列表
3. 再次按 `评论键` → 关闭评论区，退出评论状态

## 串口配置命令

连接 USB 串口（115200 波特率），发送以下命令可运行时调整配置，改动自动保存到 NVS：

| 命令 | 说明 |
|------|------|
| `help` | 显示帮助 |
| `show` | 显示当前配置 |
| `reset` | 恢复默认配置 |
| `comment_x <值>` / `comment_y <值>` | 设置评论按钮坐标 |
| `like_x <值>` / `like_y <值>` | 设置点赞坐标 |
| `share_x <值>` / `share_y <值>` | 设置分享按钮坐标 |
| `screen_w <值>` / `screen_h <值>` | 设置屏幕分辨率 |

默认配置为 `1080 x 2400`（见 [Config.cpp](Config.cpp#L4-L13)）。

## 工作原理

### HID Digitizer 报告

设备上报 5 字节触摸报告（见 [REPORT_MAP](touch.ino#L58-L78)）：

| 字段 | 说明 |
|------|------|
| Bit0 `Tip Switch` | 手指是否按下（点击/滑动） |
| Bit1 `In Range` | 指针是否在屏幕有效范围内（悬停） |
| X 坐标 | 逻辑值 `0~4500`（按屏幕宽高比映射） |
| Y 坐标 | 逻辑值 `0~10000` |

X、Y 使用**独立 Logical Max**，保证坐标比例与屏幕宽高比一致，避免横向被压缩。

### 悬停（不点击）的实现

`Tip Switch = 0` 且 `In Range = 1` 时，指针处于"抬起但未离开"的悬停状态，可以自由移动而不产生点击。本项目利用这一点实现：

- 滑动结束后悬停回到起始位置，避免下次操作瞬移
- 分享状态下在头像之间平滑移动，由 `love` 键决定是否点击

### 无阻塞动作执行器

所有触控动作（点击、滑动、悬停）被拆成若干"帧"，每帧包含坐标、`Tip`/`In Range` 状态和等待时长，由 `actionTick()` 在主循环中用 `millis()` 非阻塞执行。动作执行期间忽略新按键，避免打断动作序列。

### 触摸检测

BS816A-1 采用 CMOS 高有效输出，ESP32-C3 以浮空输入读取。驱动层实现 20ms 消抖 + 首次读取基准，避免上电/BLE 连接时的误触发。详见 [BS816A.cpp](BS816A.cpp)。

## 目录结构

```
touch/
├── touch.ino       # 主程序：BLE、HID、动作执行器、按键状态机
├── BS816A.h        # 触摸芯片驱动头文件（引脚、消抖参数）

├── Config.h        # 配置结构体与 ConfigManager 声明
├── Config.cpp      # 配置读写（NVS）与串口命令解析
└── build/          # 编译产物（建议加入 .gitignore）
```

## 坐标适配说明

代码中的坐标基于 **1080 x 2400** 分辨率实测，部分关键坐标如下（见 [touch.ino](touch.ino#L42-L54)）：

- 好友头像：`Y = 1902`，`X = {116, 308, 500, 692, 884}`
- 确认分享按钮：`(815, 2321)`
- 关闭分享面板：`(1003, 1700)`
- 关闭评论区：`(540, 726)`
- 光标锚点：`(993, 1535)`

如果你的手机分辨率或 App 版本不同，请通过串口命令或修改源码中的坐标常量进行适配。
